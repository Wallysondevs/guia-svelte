Guia Svelte

A Ana tem uma padaria, um caderno de encomendas e nenhuma paciência para atualizar planilha. Ela quer uma tela que mostre o pedido, some o total e se atualize sozinha quando ela digita. Este guia ensina a construir essa tela — do primeiro <h1> até o site publicado — usando Svelte 5 e SvelteKit, em português, para quem nunca programou.

Como este guia funciona
  • 144 aulas, uma ideia por aula, na ordem em que se aprende de verdade.
  • Toda caixa "Experimente" compila o seu código com o compilador real do Svelte e monta o componente no navegador: não é imagem, não é simulação.
  • A saída mostrada nas aulas foi colhida do compilador desta versão (svelte 5.59.2) — se o seu resultado for diferente, o código é diferente.
  • Nada de instalar nada para começar: as três primeiras aulas rodam aqui mesmo, na página.

1. Para quem é

Para quem nunca escreveu uma linha de código. O guia não supõe que você saiba JavaScript, HTML ou CSS: cada um deles aparece quando é necessário, explicado na hora, com a analogia antes do comando. Se você já programa em outra linguagem, o Nível 1 vai parecer devagar — é de propósito. O leitor que este guia atende é a Ana, e a Ana não sabe o que é uma variável.

Se você já mexeu com React ou Vue, comece pela aula Vindo de React ou Vue, na Referência. Ela mostra o mesmo componente nas três linguagens e aponta o que muda de verdade: aqui não existe useState, não existe setState, não existe useEffect com lista de dependências — existe $state, e a tela acompanha.

2. O primeiro componente, agora

Este é o mesmo componente que a primeira aula constrói. Edite o texto, clique em Rodar e veja a tela mudar. O compilador do Svelte está rodando dentro desta página.

Missão: troque o nome para o seu e clique em Rodar. Depois troque de volta para Ana e clique em Verificar.

<script>
  let nome = $state('mundo');
</script>

<h1>Olá, {nome}</h1>
<button onclick={() => (nome = 'Ana')}>chamar a Ana</button>
<script>
  let nome = $state('Ana');
</script>

<h1>Olá, {nome}</h1>
<button onclick={() => (nome = 'Ana')}>chamar a Ana</button>

3. O que você vai construir

No fim do Nível 2, a Ana tem um caderno de pedidos que funciona: ela digita o nome do cliente, escolhe os pães, o total aparece e a lista de pedidos do dia se atualiza. No Nível 3, esse caderno vira um site de verdade — com endereço, rotas, dados que vêm do servidor e formulário que grava — e vai para o ar.

No caminho, você vai esbarrar nos mesmos erros em que todo mundo esbarra: a variável sem $state que não atualiza a tela, o bloco {#if} sem fechar, o on:click copiado de um tutorial antigo. Cada aula tem uma seção "Quando dá errado" com a mensagem real do compilador, para você reconhecer o problema em vez de decorar a solução.

4. Como estudar

Uma aula por vez, na ordem, com o teclado na frente. Ler sobre componente não ensina componente: editar a caixa e ver o resultado, sim. Se a caixa mostrar uma mensagem vermelha, leia a mensagem inteira antes de mexer no código — ela diz a linha, a coluna e o que o compilador esperava.

Sem pressa na primeira semana

As aulas 1 a 12 são a base de tudo. Quem corre por elas acaba voltando. Quem entende bem o que é estado e o que é prop resolve sozinho 80% dos problemas do resto do guia.

5. O que este guia não é

Não é uma referência da API: para isso existe a documentação oficial, e a aula da Folha de Bolso aponta o caminho. Não é um curso de JavaScript avançado: o JavaScript que aparece é o necessário para a tela funcionar. E não é um guia de design: o CSS aqui é o mínimo para a coisa ficar legível e não vazar de um componente para outro.

Resumo

  • 144 aulas em cinco níveis, do primeiro componente ao site publicado.
  • Todo código das caixas é compilado e executado de verdade no seu navegador.
  • Svelte 5 com runas: $state, $derived, $effect, $props.
  • SvelteKit no Nível 3: rotas, load, formulários, sessão, deploy.
  • Sem instalar nada para estudar; para praticar, um projeto em ~/loja.
