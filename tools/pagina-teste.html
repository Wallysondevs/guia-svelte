Página de teste

Esta página só existe para o testador provar que funciona: uma caixa, uma meta e nada mais. A Ana não aparece aqui porque não é aula.

1. Uma caixa com meta de texto

Missão: mostre o contador começando em zero (o inicial começa em 7).

<script>
  let contador = $state(7);
</script>

<button onclick={() => contador++}>Cliques: {contador}</button>
<script>
  let contador = $state(0);
</script>

<button onclick={() => contador++}>Cliques: {contador}</button>

2. Uma caixa que precisa de clique

Missão: comece em 0 e chegue a 2 cliques.

<script>
  let contador = $state(1);
</script>

<button onclick={() => contador++}>Cliques: {contador}</button>
<script>
  let contador = $state(0);
</script>

<button onclick={() => contador++}>Cliques: {contador}</button>

Resumo

Se esta página passa, o testador está de pé: ele compila, monta, clica e compara.
